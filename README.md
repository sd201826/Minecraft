# MINECRAFT — Classic Creative

A single-player browser-based voxel creative game with an original Classic-inspired interface and procedural pixel textures. This is an independent fan project, not the official Minecraft game and not affiliated with Mojang or Microsoft.

## Play
Open the GitHub Pages URL. The browser loads Three.js from jsDelivr and game audio from the CC0 sound library SFXMint, so an internet connection is required.

## Controls
| Input | Action |
|---|---|
| WASD | Move |
| Mouse | Look |
| Space | Jump |
| Left click | Mine the targeted block, including water |
| Right click | Place the selected block |
| Middle click | Pick a block into the selected slot |
| 1–9 / mouse wheel | Select hotbar slot |
| B or E | Open block selection |
| F | Toggle distance fog |
| M | Toggle sound |
| G | Toggle fullscreen |
| Esc | Pause / resume |

## Included
- Nine-slot Classic-inspired hotbar with pixel-textured block thumbnails
- 32 selectable creative blocks, including individual, mineable water blocks
- Voxel-grid targeting that handles transparent water
- Shallow pond beside spawn for immediate water testing
- Procedural pixel textures and terrain, trees, shorelines and ore blocks
- Nearby chunk loading to reduce rendered geometry
- First-person movement, jumping, collision and fullscreen
- Moving slime creatures
- CC0 MP3 sound clips for mining, stone, wood, placement, water, footsteps and slimes, with a gain/compressor stage for clearer, louder playback
- Browser-local world saving

## Sound credits
The game uses sound-effect files from [SFXMint's Survival Game Sound Effects Pack](https://sfxmint.com/sets/survival-crafting). The pack page identifies the files as CC0 and provides direct CORS-enabled MP3 links. Sound selections are third-party effects, not copied from Minecraft. <https://creativecommons.org/publicdomain/zero/1.0/>

## Limits
This is a single-player creative sandbox, not a complete official Minecraft recreation. It does not include multiplayer hosting, survival mode, crafting, redstone, or third-party mod loading.
