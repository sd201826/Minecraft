# MINECRAFT — Classic Creative

A single-player browser-based voxel creative game with an original, Classic-inspired interface and procedurally generated pixel block textures. This is an independent fan project, not the official Minecraft game and not affiliated with Mojang or Microsoft.

## Play
Enable **Settings → Pages → Deploy from a branch → main → /(root)**, then open the Pages URL. Three.js is loaded from jsDelivr, so an internet connection is required.

## Controls
| Input | Action |
|---|---|
| WASD | Move |
| Mouse | Look |
| Space | Jump |
| Left click | Break the targeted block (including transparent water) |
| Right click | Place the selected block |
| Middle click | Pick a block into the selected slot |
| 1–9 / mouse wheel | Select hotbar slot |
| B or E | Open the block selection window |
| F | Toggle distance fog |
| M | Toggle sound |
| G | Toggle fullscreen |
| Esc | Pause / resume |

## Included
- Nine-slot Classic-inspired hotbar with pixel-textured isometric block icons
- 32 selectable creative blocks, including placeable and breakable water
- Voxel-grid block targeting so transparent water can be selected and mined reliably
- Procedural 16×16 pixel textures for terrain, ores, wood, leaves, glass, wool and building blocks
- Procedural 128×128 world with terrain, trees, beaches, water and ores
- Nearby chunk loading to reduce rendered geometry and improve performance
- First-person movement, collision, jumping, crosshair target outline and fullscreen
- Moving slime creatures that wander, hop, react when clicked and make sounds
- Original generated sound effects for mining, placing, jumping, footsteps and creatures
- Browser-local world saving

## Limits
This is a completed creative sandbox release, not a complete official Minecraft recreation. It does not include official game assets, multiplayer/server hosting, survival mode, crafting, redstone, or a third-party mod loader.
